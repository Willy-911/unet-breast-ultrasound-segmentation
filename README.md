# U-Net Breast Ultrasound Segmentation

This project implements a U-Net model for breast tumor segmentation using the BUSI dataset.

## Dataset
Breast Ultrasound Images Dataset (BUSI)

## Model
U-Net convolutional neural network for medical image segmentation.

## Features
- Image segmentation using U-Net
- Training with PyTorch
- 80/20 train-test split
- Accuracy evaluation

python U-Net_Code.py
